# Discussion of SNOMED code for Suspected ADHD
This document provides references to the date when the suspected ADHD is used and this not compatible to the Covid direction.

## Method for accessing SNOMED code for Attention deficit hyperactivity disorder

### Step 1: Accessing the link
The SNOMED code for Attention deficit hyperactivity disorder suspected can be found on the [NHS SNOMED CT Brower]( https://termbrowser.nhs.uk/?perspective=full&conceptId1=1863681000000108&edition=uk-edition&release=v20250730&server=https://termbrowser.nhs.uk/sct-browser-api/snomed&langRefset=999001261000000100,999000691000001104). A screenshot of the link is displayed below.


![Screenshot of the link from NHS SNOMED CT Brower](/All_materials/20250922_ADHD_Suspected_SNOMED/Slide_1.png)

### Step 2: Accessing the date of the SNOMED code

As highlighted on the screenshot below, using the mouse cursor, click on Detail tab (highlighted in red) then click on the “i icon” along the Term column (highlighted in blue).

![Screenshot listing details of Attention deficit hyperactivity disorder suspected (situation)](/All_materials/20250922_ADHD_Suspected_SNOMED/Slide_2.png)
